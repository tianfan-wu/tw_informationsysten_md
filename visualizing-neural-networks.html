01 · Network architecture

How data moves through the model

A forward pass converts raw feature values into a prediction through successive learned transformations.

01

Receive inputs

The input layer holds measured features such as pixel values, customer attributes, or encoded words.

02

Compute weighted sums

Each hidden neuron multiplies incoming values by weights and adds a learned bias.

03

Apply activation

A nonlinear activation transforms the weighted sum so the network can learn curved and complex patterns.

04

Produce output

The output layer returns a class probability, numeric estimate, or another task-specific prediction.

02 · Inside one neuron

A small computation with a large role

Every neuron combines evidence, shifts its activation threshold, and passes a transformed signal forward.

x₁ x₂ x₃
→ Σ → f(z) → a

Neuron mathematics

z = w₁x₁ + w₂x₂ + w₃x₃ + b

a = f(z)

Weights control the strength and direction of each input. The bias shifts when the neuron activates, while the activation function produces the signal sent to the next layer.

03 · Core components

Architecture defines the computation

Training determines the parameter values that make the network useful for a specific prediction task.

01

Layers

Input layers receive features, hidden layers learn intermediate representations, and output layers match the prediction task.

02

Neurons

Nodes compute a weighted sum plus a bias and then apply an activation function. Together, many neurons learn distributed patterns.

03

Weights and biases

These trainable values determine the strength of connections and the thresholds at which neurons respond.

04

Activation functions

ReLU, max(0, z), is efficient in hidden layers. Sigmoid maps an output to 0–1 and is useful for binary probabilities.

05

Loss functions

Mean squared error measures regression error. Cross-entropy penalizes probability assigned away from the correct class.

06

Optimization

SGD follows gradients estimated from data batches. Adam adapts the update size using first- and second-moment estimates.

04 · Training dynamics

Learning is a measured cycle

The network repeats prediction and correction until validation performance stabilizes.

1 · Forward pass

Compute predictions using the network's current weights and biases.

2 · Loss

Compare predictions with target values and summarize the error.

3 · Backpropagation

Use the chain rule to calculate how each parameter contributed to the error.

4 · Optimizer

Update weights and biases in the direction expected to reduce the loss.

One epoch is one complete pass through the training set. A widening gap between training and validation loss can signal overfitting.

05 · Neural Network Playground

Controlled experiments reveal model behavior

Changing one setting at a time makes the relationship between data difficulty and model capacity easier to interpret.

01

Data geometry

Linearly separated clusters need a simple boundary. Circles and spirals require nonlinear transformations.

02

Noise

Greater overlap weakens class separation and makes test performance less stable.

03

Feature selection

Squared or interaction features can expose a pattern that raw x₁ and x₂ do not represent directly.

04

Layer depth

Additional neurons increase capacity, but unnecessary depth adds computation and overfitting risk.

06 · Reading the visualization

Learned patterns become visible

The display exposes both intermediate representations and warning signals during training.

Node heatmaps

Show which input regions activate each neuron and how hidden features change across layers.

Connection lines

Color indicates the sign of a weight; thickness indicates its magnitude.

Decision surface

Background color represents the predicted class and confidence across feature space.

Training and test loss

Together they reveal learning progress, underfitting, and possible overfitting.

08 · Portfolio reflection

Learning through visualization

175 words · Professional portfolio artifact

Creating this neural-network visualization strengthened my understanding of how architecture and training choices shape model behavior. Mapping the forward pass from input features through hidden layers to an output made weights, biases, and activation functions feel less abstract because I could see how each stage transforms information. TensorFlow Playground added an experimental perspective. Changing the dataset, noise level, selected features, and hidden-layer depth showed that model capacity must match the structure and difficulty of the problem. Simple boundaries required little complexity, while circular or spiral patterns benefited from nonlinear features and additional neurons. Higher noise made the learned boundary less stable and increased the need to compare training and test loss. I also learned that a visually complex network is not automatically a better model; unnecessary depth can increase computation and overfitting risk. Adding this artifact to my professional portfolio extends my earlier algorithm guide by showing how a model learns, not only which algorithm to select. It demonstrates my ability to connect technical concepts with clear visual communication for analysts, developers, and business stakeholders.
